# Developer documentation

This directory records established context needed to implement, review, and maintain `sqlite-schema`.

The documentation has three layers:

- Top-level documents describe the architectural mental model and stable system boundaries.
- `design/` documents own the detailed contract and rationale for one design topic.
- `decision-log.md` records when a decision changed and links to the document that owns the current rule.

Implementation tasks, milestone progress, and tentative proposals belong in the issue tracker rather than these documents.
When a design decision changes, update its canonical document in the same change and add a decision-log entry when the chronology remains useful.
